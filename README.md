# La Praia

A pizza restaurant web app with an AI ordering assistant.

## Project Structure

```
frontend/     Client-side app (index.html, styles.css, app.js)
backend/      Server-side code and API logic
data/         Menu data and other structured data files
prompts/      System/assistant prompts for the bot
CLAUDE.md     Rules and conventions for AI-assisted development
README.md     This file
```

No application logic has been implemented yet — this is the initial project scaffold.
